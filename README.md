这是一个涉及前后端开发的项目。

后端采用基于springcloud的微服务架构，共拆分为5个微服务。通过OpenFeign，实现了服务间的无缝调用。此外，后端项目还整合了Nginx、Nacos、springcloudgateway、MySQL、Redis、RabbitMQ、Elasticsearch等12个主流Java后端开发组件。

前端则基于Vue3框架，以JavaScript作为主要开发语言。利用Axios与服务器进行高效的数据交互，并选用了Element-Plus作为第三方组件库，以丰富和美化系统界面
